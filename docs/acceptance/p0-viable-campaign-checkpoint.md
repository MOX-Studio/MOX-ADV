# P0 · проверка жизнеспособного черновика (#241)

Сценарий готовит личную контрольную точку [#241](https://github.com/MOX-Studio/MOX-ADV/issues/241). Он не записывает и не подразумевает решение владельца.

## Граница безопасности

- Только официальные read-only API Яндекс Директа и Метрики и публичная first-party страница бизнеса.
- Личные кабинеты Яндекса, provider mutations, выдача live authority, показы и расходы запрещены.
- В репозиторий попадает псевдонимизированный снимок: без OAuth-токенов и исходных provider IDs.
- Управляемый браузерный сценарий является фикстурой и не заменяет независимый read-only снимок.

## Воспроизведение

Из `sites/p0-production/`:

```bash
npm run capture:p0-viable-evidence
UPDATE_P0_VIABLE_CAMPAIGN_ACCEPTANCE=1 node --test tests/viable-campaign-acceptance.test.mjs
npm run test:contract
npm run test:e2e
```

Проверяемые артефакты:

- `tests/evidence/p0-viable-campaign-real-business.json` — независимые текущие доказательства реального бизнеса;
- `tests/evidence/p0-viable-campaign-acceptance.json` — машиночитаемая приёмка #238;
- `tests/fixtures/product-mvp/*` — отдельно помеченные управляемые фикстуры, не независимые доказательства.

## Что лично проверить при 1920×1080

Откройте локальный Dashboard `http://127.0.0.1:19243/` только через UI.

1. В положительном сценарии виден минимум один редактируемый Campaign Draft со статусом `VIABLE`.
2. У `VIABLE` пройдены все жёсткие проверки; профиль создания полный; сравнительный балл, покрытие и чувствительность не названы прогнозом.
3. Редактирование меняет новую версию черновика и требует повторной проверки, а не сохраняет прежний балл или полномочие.
4. В честном сценарии `VIABLE` отсутствует, показана точная причина и действие с приоритетом 1.
5. Фикстурные и независимые доказательства визуально и машиночитаемо разделены.
6. Нет внешней записи, выдачи полномочия, показов или расходов.

## Решение владельца

Только владелец #241 может записать `ACCEPTED` или вернуть функцию в новые задачи. До этого артефакт обязан сохранять:

```text
human_checkpoint.verdict = PENDING_HUMAN_VERDICT
implementation_may_claim_acceptance = false
```
