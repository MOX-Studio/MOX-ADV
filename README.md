# MOX-ADV

Борд для подготовки рекламы в Яндекс Директе под цель, срок и общий бюджет бизнеса.

**Цель → Сбор сведений → Стратегия → Кампании.** Владелец задаёт цель. Один Codex исследует варианты, готовит объявления и исправляет найденные недостатки. Скрипты собирают данные и проверяют результат.

Сохранённые рабочие данные, токены и частные исследовательские выгрузки остаются локальными. Старые демо на Vercel и GitHub Pages не являются рабочим Dashboard.

## Что умеет борд

- Принимает измеримую цель: обращения, оплаченные заказы, выручку, прибыль или другой результат; учитывает правила подсчёта, регион, срок и бюджет.
- Показывает сведения о сайте, предложении, конкурентах и спросе. Использует Wordstat и доступные данные Директа и Метрики; отмечает, каких данных не хватает.
- Готовит стратегию, кампании, группы, объявления, поисковые фразы, минус-фразы и план расходов.
- Показывает причины выбора, условия и ограничения. Сохраняет этапы и версии, чтобы продолжить прерванную подготовку.

## Как пользоваться

1. Откройте проект в Codex и [Dashboard](http://127.0.0.1:19243/).
2. На этапе «Цель» укажите нужный результат, регион, срок и общий бюджет. Нажмите «Сохранить цель».
3. Нажмите «Начать подготовку». Сохранение цели само по себе её не запускает. Дальше работу ведёт тот же Codex.
4. Просмотрите «Сбор сведений», «Стратегию» и «Кампании». Ключи находятся внутри кампании, в блоке «Поисковые фразы» нужной группы; минус-фразы доступны у группы и кампании.

Для нового прохода раскройте «Подготовить заново». Если доступно «Продолжить по собранным сведениям», можно использовать уже сохранённые данные.

## Что означает результат

Готовые кампании — черновики. Завершение подготовки не запускает рекламу и не расходует бюджет. Проверки черновика и прогноз достижения цели показаны отдельно; фактическую эффективность можно узнать только по результатам рекламы.

Управление действующей рекламой, мониторинг и дополнительные каналы пока находятся в разработке.

## Для разработки

Нужен Node.js 22.13 или новее.

```sh
git clone https://github.com/MOX-Studio/MOX-ADV.git
cd MOX-ADV/dashboard
npm ci
npm run dev:stable
```

Если Dashboard уже запущен, откройте существующий экземпляр на `http://127.0.0.1:19243/`. Подключения и особенности первого запуска описаны в [инструкции Dashboard](dashboard/README.md).
