Пайплайн выдаёт полный Campaign Draft — либо не выдаёт Draft вообще

Пройдите базовые и пограничные сценарии. Демонстрация проверяет продуктовый контракт: агент сам устраняет безопасно исправимые недостатки и обращается к человеку только за объективно недоступным обязательным входом.

THROWAWAY PROTOTYPE Только для решения вопроса карты.
Без API-вызовов и внешних записей.
Проверяемый вопрос. Достаточно ли двух терминальных исходов — «полный Draft» и «точечный пакет запросов без Draft» — чтобы упрощённый пайплайн честно работал на положительных и пограничных сценариях без score, rank, readiness-статусов и пользовательского чек-листа?

Пошаговые сценарии

Выберите вкладку и нажимайте шаги по порядку. Каждый сценарий начинается с одинакового набора известных фактов.

Свободная проверка

Меняйте входы в любом порядке, затем запускайте формирование. Любое изменение удаляет прежний результат.

Известные входы

Утверждённые бизнес-решения и доказательства, доступные агенту до генерации.

Терминальный результат

Только полный Campaign Draft либо точечный пакет запросов. Промежуточный Draft не показывается.

Это модель продуктового поведения, а не проверка актуальной схемы Yandex Direct API. Полнота Direct Projection здесь означает наличие всех выбранных полей упрощённого контракта; будущий модуль публикации выполняет свежий API preflight и отдельное разрешение человека.
