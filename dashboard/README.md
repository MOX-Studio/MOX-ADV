## Локальный запуск

Если борд уже работает, просто откройте ссылку. Иначе в настроенной рабочей копии выполните:

```sh
cd dashboard
npm run dev:stable
```

Нужен Node.js 22.13 или новее. При первой установке зависимостей выполните `npm ci` в `dashboard/`. Оставьте терминал работающим и откройте [Dashboard](http://127.0.0.1:19243/).

**На 11 сентября 2026 года новый pipeline ещё не опубликован в коде GitHub.** Инструкция относится к актуальной локальной копии: в старом коде нет `dev:stable` и части новых возможностей. Настройки источников и сохранённые результаты также не входят в новый клон.

## Подключения

- **Codex:** уже настроенная сессия ведёт исследование, стратегию и подготовку объявлений.
- **Директ и Метрика:** чтение через API; нужны токены и доступ к нужному аккаунту и счётчику.
- **Wordstat:** авторизованный сеанс Яндекса и отдельный браузер для сбора. Сервис запускается при сборе сведений.
- **Сайт и публичные источники:** сведения о предложении, посадочных страницах и конкурентах.

Настройки находятся в локальном `dashboard/.env.local`; токены в GitHub не публикуются. Отсутствующие данные отмечаются как недоступные.

## Работа в борде

Сохраните «Цель» и нажмите «Начать подготовку». Дальше работает тот же Codex. Если борд ожидает его, продолжите работу в связанной с проектом сессии.

Результат смотрите в «Кампаниях». Раскройте кампанию, затем «Поисковые фразы» нужной группы. Там же находятся минус-фразы группы; общие исключения — в «Минус-фразах кампании».

Этапы сохраняются. Владельцу не нужно загружать технические файлы вручную. Готовый результат — черновики; публикация и расходы остаются отдельной задачей.
